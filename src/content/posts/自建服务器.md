## Windows端部署服务器

1. [进入Easytier下载页面](https://easytier.cn/guide/download.html#latest)

2. 根据自身网络情况，配置**GitHub加速**，**根据操作系统筛选**选择**Windows**，**根据硬件架构筛选**选择**x86_64**

:::important
图示为**64位操作系统**，如果你是**32位操作系统**，请在**根据硬件架构筛选**中，选择**x86**
:::

![图片](../../assets/images/服务器部署/服务器部署-20.png)

---

## 两种不同的Easytier服务端部署方式（按需选择一种即可）

1. [Easytier-cli模式](#easytier-cli模式)（命令行界面适合不做任何修改开箱即用）
2. [Easytier-cli模式](#easytier-gui模式)（拥有图形化界面，适合自定义配置）

![图片](../../assets/images/服务器部署/服务器部署-21.png)

---

### Easytier-cli模式

1. 下载**命令行程序CLI**，点击下方的**zip**开始下载

2. **解压后**进入文件夹运行**Easytier-core.exe**即可

![图片](../../assets/images/服务器部署/服务器部署-22.png)

3. 随后你便可以[使用astral连接你的自定义服务器](#使用Astral连接到您的服务器)

:::important
请注意检查**服务器控制台中**的**防火墙**是否放行**tcp和udp协议**的**11010端口**，你可以使用[tcping](https://www.itdog.cn/tcping/),输入**ip:11010**来检查端口是否开放
:::

:::tip
你可以自行访问[easytier官网](https://easytier.cn)来查看更多有关配置的信息
:::

---

### Easytier-gui模式

1. 下载**图形界面程序GUI**，点击下方的**exe**开始下载

2. 随后双击安装，打开**Easytier-GUI**

:::important
如果页面为英文，点击左下角切换为中文
:::

![图片](../../assets/images/服务器部署/服务器部署-23.png)

3. 随后点击**右上角创建新网络**

![图片](../../assets/images/服务器部署/服务器部署-24.png)

4. 随后划到最下面点击**运行网络**即可 

![图片](../../assets/images/服务器部署/服务器部署-28.png)

5. 随后你便可以[使用astral连接你的自定义服务器](#使用Astral连接到您的服务器)

:::important
请注意检查**服务器控制台中**的**防火墙**是否放行**tcp和udp协议**的**11010端口**，你可以使用[tcping](https://www.itdog.cn/tcping/),输入**ip:11010**来检查端口是否开放
:::

:::tip
你可以自行访问[easytier官网](https://easytier.cn)来查看更多有关配置的信息
:::

## linux端一键部署服务器

> 📋 **示例环境：** Debian12.5（x86_64架构）（其他Linux操作系统类似）

---

### 🔑 使用ssh工具连接到服务器

> 📋 **示例环境：** ssh工具为：[FinalShell](https://www.hostbuf.com/t/988.html)（其他ssh工具类似）（⚠️下载可能需要科学上网）

:::important
**所有服务器信息请以服务器提供商提供的信息为准**
:::

1. 进入**FinalShell**，点击左上角**文件夹**，随后按照图片标记顺序操作

![进入ssh工具](../../assets/images/服务器部署/服务器部署-1.png)

2. 在弹出的窗口中，**名称**填写服务器的名称，主要用于在**FinalShell**中区分别的服务器，**主机**处填写**服务器提供商**给你的服务器ip地址，**端口**处填写**服务器提供商**给你的ssh端口，**用户名**处填写**服务器提供商**给你的用户名，**密码**处填写**服务器提供商**给你的密码，随后点击下方**确定**

:::important
一般ssh用户名默认为**root**,端口默认为**22**,**但服务器提供商可能会为了安全进行更改，请以网站面板显示的信息为主**
:::

![ssh连接](../../assets/images/服务器部署/服务器部署-2.png)

3. 在弹出的窗口中，双击你刚刚创建的服务器（比如我这里创建的服务器名称为**枣庄**，请无视马赛克部分）

![ssh连接](../../assets/images/服务器部署/服务器部署-3.png)

4. 随后你将会进入ssh页面（下图中的ip地址已被打码，请无视）

![ssh连接](../../assets/images/服务器部署/服务器部署-4.png)

:::important
**界面可能会有点不一样，因为所使用的Linux系统不同**
:::

> ✅ **服务器连接完成！** 恭喜你成功连接到你的服务器了，现在可以进行下一步了

---

### ⚙️ 安装ET服务端

1. 使用该命令更新软件源

:::important
**如果该命令无法更新请自行查找更新软件源命令**
:::

```
apt update
```

![图片](../../assets/images/服务器部署/服务器部署-5.png)

2. 检查是否已安装**unzip**，在**FinalShell**中的窗口中输入

```
unzip -v
```

![安装unzip](../../assets/images/服务器部署/服务器部署-8.png)

3. 如果显示如**上图**的信息，则使用该命令安装**unzip**

:::important
如果该命令无法安装请自行查找安装指令
:::

```
apt install unzip
```

---

#### 关于乌班图（Ubuntu）系统，如果不是请跳到第4步

:::important
**如果你使用的是乌班图（Ubuntu）系统，那么安装unzip时将会弹出此窗口，请不要慌张，点击键盘左上角的**ESC**键退出即可**
:::

![重启内核](../../assets/images/服务器部署/服务器部署-6.png)

**最后来到这，请继续下一步操作**

![重启内核](../../assets/images/服务器部署/服务器部署-7.png)

---

4. 检查unzip是否安装成功，如下图所示

```
unzip -v 
```

![安装unzip](../../assets/images/服务器部署/服务器部署-9.png)

5. 安装EasyTier

**一键安装命令**

```
wget -O /tmp/easytier.sh "https://raw.githubusercontent.com/EasyTier/EasyTier/main/script/install.sh" && bash /tmp/easytier.sh install --gh-proxy https://ghfast.top/
```

:::important
如果提示如下报错
:::

![安装unzip](../../assets/images/服务器部署/服务器部署-10.png)

6. 请使用该命令安装依赖

```
apt install curl
```

7. 随后可能会弹出确认，按**Y**后回车即可，安装完成后请**再次**使用一键命令安装easytier

![安装unzip](../../assets/images/服务器部署/服务器部署-11.png)

:::important
**如果已经尝试多次该命令但仍然无法安装请跳转到**[手动部署教程](#linux端手动部署服务器)
:::

**easytier最终安装效果**

![安装ET](../../assets/images/服务器部署/服务器部署-12.png)

8. 使用该命令启动EasyTier，注意启动后不会有任何提示

```
systemctl start easytier@default
```

> ✅ **EasyTier安装完成！** 恭喜您成功安装EasyTier了，现在可以进行下一步了

---

### 进入默认EasyTier配置文件目录

1. 在**FinalShell**中点击下方的**opt**，随后进入**easytier**根目录

![回退](../../assets/images/服务器部署/服务器部署-13.png)

2. 随后点击**config**

![进入目录](../../assets/images/服务器部署/服务器部署-14.png)

3. 双击**Default.conf**文件

![配置](../../assets/images/服务器部署/服务器部署-15.png)

4. **最终打开效果**

![最终](../../assets/images/服务器部署/服务器部署-16.png)

> ✅ **打开EasyTier配置文件！** 恭喜您成功打开EasyTier配置文件了，现在可以进行下一步了

---

### 修改EasyTier配置文件

1. **复制以下配置**，回到刚刚打开的配置文件，使用键盘左下角的**CTRL+A**全选旧的配置（你也可以在打开的文件内使用鼠标右键再点击全选），再把新的配置**粘贴**进去

```
hostname = "" #更改想要的服务器名称,留空将随机生成，注意astral-game不会显示服务器名字
dhcp = true
listeners = [
    "tcp://0.0.0.0:11010",
    "udp://0.0.0.0:11010",
]
rpc_portal = "127.0.0.1:15888"

[network_identity]
network_name = ""
network_secret = ""

[flags]
enable_kcp_proxy = true
enable_quic_proxy = true
latency_first = true
```

2. 随后点击上方的**文件**并点击**保存**

![配置](../../assets/images/服务器部署/服务器部署-17.png)

:::important
**您在打开或者保存配置的时候，会闪过这个窗口，请不用理会**
:::

![配置](../../assets/images/服务器部署/服务器部署-18.png)

:::important
如果你使用的是别的ssh工具，可能需要下载的自己电脑上更改后再上传回服务器替换，具体请自己百度
:::

3. 输入该指令重启EasyTier服务，注意重启后不会有任何提示

```
systemctl restart easytier@default
```

![重启](../../assets/images/服务器部署/服务器部署-19.png)

:::important
您每次改动easytier的配置文件，改完后均需重启一次easytier（另外请记得**保存**你修改的文件）
:::

:::tip
如果你买的是大厂的服务器，需要前往防火墙控制台页面放行端口，你需要放行端口**11010**，协议为**UDP**和**TCP**，很抱歉因为我是借的服务器所以无法进行图文演示
:::

> ✅ **完成EasyTier的文件配置！** 恭喜您已完成EasyTier的文件配置了，现在可以进行下一步了

---

### 使用Astral连接到您的服务器

1. 来到astral-game主页，点击左侧的**服务器**，随后点击右下角的**加号**来添加服务器（名称随意，主要用于在AS中区分其他服务器）

:::important
复制以下格式，**IP修改为你的服务器ip**，端口如果你没有在配置文件中修改，则默认为**11010**
:::

```
tcp://IP:11010
```

```
udp://IP:11010
```

![图片](../../assets/images/MC联机教程/MC4.png)

2. 添加服务器后，记得在右侧**打开**以启用服务器

![图片](../../assets/images/AstralGame使用教程/ASG1.png)

3. 随后您便可以像公益服务器一样正常使用您的服务器了

:::important
如果您不希望把服务器给陌生人用，那么请不要随意分享您的服务器地址，并告知您的朋友不要随意分享
:::

:::tip
如果您需要更安全的服务器配置，你可以在配置文件中修该端口为10000-60000之间（[教程](#修改et服务端口)）
:::

### linux端手动部署服务器

> 📋 **示例环境：** Debian12.5（x86_64架构）（其他Linux操作系统类似）

1. 下载easytier的linux包（在QQ群文件），**随后将该文件移动到自己电脑桌面方便后续使用**

:::important
图示文件可能与群文件中的**版本不同**，请选择无视（因为群文件会更新）
:::

![退出](../../assets/images/服务器部署/服务器部署-25.png)

![退出](../../assets/images/服务器部署/服务器部署-26.png)

![退出](../../assets/images/服务器部署/服务器部署-27.png)

2. 使用以下命令创建文件夹

:::important
**需按顺序从上到下分步执行**
:::

```
cd /
```

```
mkdir easytier
```

3. 点击**右边**的刷新，随后进入**easytier文件夹**

![退出](../../assets/images/服务器部署/服务器部署-29.png)

4. 将刚刚下载的easytier压缩包拖入该目录

![退出](../../assets/images/服务器部署/服务器部署-30.png)

**最终状态**

![退出](../../assets/images/服务器部署/服务器部署-31.png)

5. 在上方窗口输入该命令

```
cd easytier && unzip easytier-linux-x86_64-v2.6.4.zip && cd easytier-linux-x86_64 && ./easytier-cli service install -c /easytier/easytier-linux-x86_64/config/default.conf && ./easytier-cli service start
```

6. 随后，您可以[使用Astral连接到您的服务器](#使用Astral连接到您的服务器)

:::important
如果您不希望把服务器给陌生人用，那么请不要随意分享您的服务器地址，并告知您的朋友不要随意分享
:::

:::tip
如果您需要更安全的服务器配置，你可以在配置文件中修该端口为10000-60000之间（[教程](#修改et服务端口)）
:::

### 修改ET服务端口

:::important
该教程仅为linux端，Windows端请看[easytier官网](https://easytier.cn)
:::

1. 来到**FinalShell**，并ssh连接上你的服务器，进入**easytier根目录**

:::important
如果你使用的是**一键安装命令**，则在**opt/easytier目录**下；如果你使用的是**手动部署**，则在**easytier目录**下。**以下图示为手动部署的图片**
:::

![退出](../../assets/images/服务器部署/服务器部署-32.png)

2. 修改**listeners**中的配置，将**11010端口**改为**10000-60000**之间的任意端口

:::important
**注意修改后的端口不能被其他服务占用，否则会导致easytier无法正常启动**
:::

```
listeners = [
    "tcp://0.0.0.0:11010",
    "udp://0.0.0.0:11010",
]
```

:::important
改完配置文件后请点击左上角**文件**，随后选择**保存**，**FinalShell**将会自动上传替换配置文件
:::

3. 随后使用该命令重启easytier即可

:::important
**注意linux端的手动部署和一键部署的easytier重启命令不同**
:::

#### 手动部署

```
cd / && cd easytier/easytier-linux-x86_64 && ./easytier-cli service stop && ./easytier-cli service start
```

#### 一键部署

```
systemctl restart easytier@default
```
